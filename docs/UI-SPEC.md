# UI-SPEC — контракт интерфейса CallMyPromts

> Статус: **действует с 2026-09-05**. Версия 1.0.
> Правила: [`docs/RULES.md §5`](docs/RULES.md:1). Требования: [`docs/SPEC.md §7`](docs/SPEC.md:1).
> Источники решений: дизайн-система SpecKit [`styles.css:16`](../zoo-kit/SpecKit/dashboard/styles.css:16),
> Material 3 (роли цвета, токены движения), WCAG 2.2, разбор 493 функций ClipClip.

## 0. Решение о вариативности

Владелец отказался фиксировать один вариант оформления. Поэтому реализуются **все три
раскладки и обе темы**, выбор переносится в настройки. Это дороже на ~200 строк CSS, но
дешевле, чем переделывать после «не нравится».

Механизм: раскладка и тема — атрибуты на `<html>`, всё остальное решает CSS.

```html
<html data-layout="hybrid" data-theme="dark" data-motion="full" data-accent="teal">
```

Логика не знает о раскладке. Это следствие [`ENTITY-MAP §4.3`](docs/ENTITY-MAP.md:1):
изменение вида не должно задевать модули данных.

## 1. Токены

### 1.1 Поверхности и текст

| Токен | Светлая | Тёмная | Назначение |
|---|---|---|---|
| `--surface` | `#f0f2f5` | `#1b1b1f` | фон окна |
| `--surface-2` | `#e7e5e4` | `#26262b` | утопленные поля, поиск |
| `--surface-3` | `#e8eaed` | `#2e2e34` | наведение на строку |
| `--surface-sel` | `#dfe3e8` | `#36363d` | выбранная строка |
| `--text` | `#1e2938` | `#e4e2e6` | основной текст |
| `--text-muted` | `#6b7280` | `#9a97a0` | подписи, «почему» |
| `--outline` | `#c4c7c5` | `#45474a` | границы, разделители |

Светлая база и тень взяты из существующих решений владельца: `#f0f2f5` из SpecKit,
тень `rgba(87,82,121,.14)` из его же настройки VS Code. Тёмная построена по Material 3
dark surface.

### 1.2 Акценты

Пять вариантов, переключаются `data-accent`. Красный и зелёный **не предлагаются**: они
заняты статусами, и акцент того же тона сделал бы ошибку неотличимой от кнопки.

| `data-accent` | Светлая | Тёмная | Контраст к surface |
|---|---|---|---|
| `teal` (по умолчанию) | `#006666` | `#4db6ac` | 5.9 / 6.4 |
| `indigo` | `#4338ca` | `#a5b4fc` | 6.8 / 7.1 |
| `amber` | `#92400e` | `#fcd34d` | 6.1 / 9.8 |
| `rose` | `#9f1239` | `#fda4af` | 7.4 / 7.9 |
| `slate` | `#334155` | `#cbd5e1` | 9.1 / 9.4 |

Все пары ≥ 4.5:1 для текста и ≥ 3:1 для элементов — требование
[`WCAG 1.4.11`](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html).

### 1.3 Состояния — ровно четыре

| Класс | Значок | Слово | Светлая | Тёмная |
|---|---|---|---|---|
| `is-good` | `✓` | «в норме» | `#10b981` | `#34d399` |
| `is-warn` | `!` | «внимание» | `#f59e0b` | `#fbbf24` |
| `is-bad` | `✕` | «сломано» | `#ef4444` | `#f87171` |
| `is-none` | `–` | «нет данных» | `#9ca3af` | `#6b7280` |

Плашка обязана содержать **значок и слово**, не только цвет. Причина: ~8% мужчин имеют
протанопию, и цвет для них не сигнал.

### 1.4 Форма, шрифт, плотность

```
--radius-sm  6px    --radius-md 10px    --radius-lg 14px
шаг сетки    4px
--font       Inter, "Segoe UI", system-ui, sans-serif
--mono       "JetBrains Mono", "Cascadia Code", Consolas, monospace
```

| Роль текста | Размер | Вес |
|---|---|---|
| заголовок раздела | 22px | 700 |
| заголовок блока | 15px | 650 |
| основной | 13px | 500 |
| подпись | 11.5px | 500 |
| моно | 12px | 500 |

Скругления 6/10/14 — из настройки VS Code владельца. Шкала размеров — из SpecKit.

`data-density`: `compact` умножает вертикальные отступы на 0.75, `comfortable` на 1.25.
`--font-scale` от 100 до 200 применяется к `html { font-size }`.

### 1.5 Движение

Токены Material 3, проверены по первоисточнику:

```
--ease-standard      cubic-bezier(0.2, 0.0, 0, 1.0)
--ease-decelerate    cubic-bezier(0, 0, 0, 1)
--ease-accelerate    cubic-bezier(0.3, 0, 1, 1)
--ease-emph-dec      cubic-bezier(0.05, 0.7, 0.1, 1.0)
--ease-emph-acc      cubic-bezier(0.3, 0.0, 0.8, 0.15)

--dur-instant 100ms   --dur-fast 150ms   --dur-base 250ms   --dur-slow 400ms
```

| Событие | Длительность | Кривая | Свойства |
|---|---|---|---|
| появление окна | `--dur-fast` | `emph-dec` | `opacity`, `transform: scale(.98)→1` |
| скрытие окна | `--dur-instant` | `accelerate` | `opacity`, `transform` |
| подсветка строки | `--dur-instant` | `standard` | `background-color` |
| раскрытие превью | `--dur-base` | `decelerate` | `opacity`, `transform: translateX` |
| смена группы | `--dur-base` | `standard` | `opacity` |
| новая запись в журнале | `--dur-base` | `emph-dec` | `opacity`, `transform: translateY(-8px)→0` |
| вспышка «скопировано» | `--dur-slow` | `decelerate` | `opacity` |
| пульс индикатора сервиса | 2000ms, цикл | `linear` | `opacity` |

**Анимируются только `transform` и `opacity`**, кроме подсветки строки, где меняется
`background-color` — это одно свойство на одном элементе, перерисовка дешёвая.

Запрещено анимировать: `width`, `height`, `top`, `left`, `box-shadow`, `filter`,
`backdrop-filter`. Причина: reflow и перерисовка ломают плавность на слабых машинах и
при удалённом подключении.

`data-motion`: `full` — как в таблице; `reduced` — все длительности 1ms, кроме `opacity`;
`off` — `transition: none`. При системном `prefers-reduced-motion: reduce` уровень
принудительно понижается до `reduced`, даже если в настройках `full`.

## 2. Три раскладки

### 2.1 `palette` — скорость

```

                    │  🔍 ревью|                                    │
                    ├───────────────────────────────────────────────┤
                    │ 1 ●Ревью кода            код    ⌗12  █████    │
                    │ 2  План перед действием  ядро   ⌗8   ███░░    │
                    │ 3  Разбор без кода       код    ⌗5   ███░░    │
                    │ ─────────────────────────────────────────     │
                    │    Безопасность          код    ⌗2   █░░░░    │

        │ ГРУППЫ                   │  2. Безопасность — валид…      │
        │ ▸ Код             (9)    │                                │
        │ ▸ Ядро            (5)    │  [Вставить] [Правка] [В буфер] │

        └───────────────────────────────────────────────────────────┘
```

900×560, две колонки 320/580, превью всегда видно, есть строка состояния.

### 2.3 `hybrid` — по умолчанию

Стартует как `palette`. `Space` раскрывает панель превью справа за `--dur-base`,
`Space` повторно — скрывает. Ширина 640 → 1040.

Причина выбора по умолчанию: быстро в обычном случае, подробно по требованию.

## 4. Поведение клавиатуры

Модель взята из ClipClip: одно нажатие — один смысл.

| Клавиша | Действие |
|---|---|
| `1`…`9` | выбрать закреплённый и **сразу вставить** — только при пустом поиске |
| `↑` `↓` | перемещение по списку |
| `Enter` | вставить выбранный |
| `Ctrl+Enter` | вставить без переводов строк в конце |
| `Tab` | скопировать в буфер, не вставляя |
| `Shift+Tab` | не перехватывается: переход фокуса остаётся браузеру (`REQ-UI-A11Y`) |
| `Space` | превью (в `hybrid` — раскрыть панель) — только при пустом поиске |
| `F2` | правка выбранного |
| `Esc` | закрыть без действия |
| печатные символы | ввод в поиск, независимо от раскладки |

**Оговорка «только при пустом поиске» относится и к цифрам, и к пробелу**, и по
одной причине: пока поле поиска пусто, нажатие — это команда, как только в нём
что-то есть — это ввод. Иначе `1` было бы неоднозначно между «позиция 1» и
«символ 1», а пробел вообще нельзя было бы набрать: запрос «ревью кода» состоит
из двух слов, и перехват пробела оставил бы поиск односложным.

Уточнение внесено после провала E2E-теста U-17: тест набирал запрос и ждал, что
`Space` раскроет превью. Код вёл себя верно, недоговаривала таблица —
[`keyAction()`](ui/views/keys.js:28) отдаёт пробел полю ввода с самого начала.

## 5. Состояния экранов

| Ситуация | Состояние | Что показываем |
|---|---|---|
| промпт прочитан и валиден | `is-good` | обычная строка |
| промпт с предупреждением (`V-P-5`, `V-P-10`) | `is-warn` | значок `!` и причина в превью |
| промпт битый (`V-P-1`, `V-P-8`) | `is-bad` | значок `✕`, строка не вставляется, причина видна |
| библиотека пуста | `is-none` | «промптов нет — создайте первый через Ctrl+Shift+S» |
| поиск без результатов | `is-none` | «ничего не найдено по запросу «…»» |
| журнал пуст | `is-none` | «записей нет — слежка включена, скопируйте что-нибудь» |
| слежка на паузе | `is-warn` | «слежка приостановлена» |
| сервис не запущен | `is-none` | «сервис остановлен» + кнопка запуска |
| хоткей занят | `is-bad` | красное поле + имя перехватчика + предложение замены |
| хоткей не назначен | `is-none` | «не назначена» |

Пустое состояние всегда содержит **причину и следующее действие**. «0 промптов» без
объяснения — то же, что молчание.

## 6. Доступность

- каждое поле имеет `<label for>`;
- активный раздел помечен `aria-current="page"`;
- список — `role="listbox"`, строки — `role="option"` с `aria-selected`;
- порядок табуляции совпадает с визуальным;
- ошибка привязана к полю через `aria-describedby`;
- нет горизонтального скролла: длинные пути и токены переносятся
  `overflow-wrap: anywhere`, у flex-детей `min-width: 0`;
- фокус видим: обводка 2px акцентным цветом, не убирается `outline: none`;
- контраст: текст ≥ 4.5:1, элементы и границы ≥ 3:1.

## 7. Проверяемые утверждения для E2E

| # | Утверждение | Как проверяется |
|---|---|---|
| U-1 | все три раскладки открываются и содержат `pickerList` | перебор `data-layout` |
| U-2 | обе темы дают контраст ≥ 3:1 на границах и плашках | вычисление контраста в браузере |
| U-3 | ни одна плашка не несёт смысл только цветом | у каждой `.is-*` есть значок и слово |
| U-4 | окно видно ≤ 200 мс после команды | замер от вызова до `visible` |
| U-5 | цифра 1 вставляет первый закреплённый | нажатие → проверка буфера |
| U-6 | Esc закрывает без действия | буфер не изменился |
| U-7 | Tab копирует, но не вставляет | буфер изменился, поле пусто |
| U-8 | поиск находит по названию, группе и телу | 3 запроса |
| U-9 | битый промпт помечен `✕` и не вставляется | фикстура с пустым телом |
| U-10 | один битый не ломает остальные | 1 битый из 5 → 4 работают |
| U-11 | контекстное меню журнала — ровно 3 пункта | подсчёт кнопок |
| U-12 | «сохранить как промпт» показывает список групп | подменю содержит группы из API |
| U-13 | занятый хоткей показан красным с именем перехватчика | подстановка конфликта |
| U-14 | нет данных — прочерк с причиной, ноль `undefined`/`NaN` | пустая библиотека и пустой журнал |
| U-15 | нет горизонтального скролла на 800×600 | `scrollWidth <= clientWidth` |
| U-16 | `prefers-reduced-motion` понижает уровень движения | эмуляция медиазапроса |
| U-17 | клавиатура проходит все разделы настроек | Tab по порядку |
| U-18 | запрос к API без токена возвращает 401 | `fetch` без заголовка |
| U-19 | счётчик использований растёт после вставки | `used` до и после |
| U-20 | смена темы не требует перезагрузки страницы | атрибут меняется, стили применяются |

## 8. Порядок работ по интерфейсу

1. Разметка окна выбора и id из §3.1 — с честной пустотой, без данных.
2. Токены и обе темы (§1) одним файлом `ui/styles/tokens.css`.
3. Три раскладки (§2) в `ui/styles/layouts.css` — только CSS, DOM один.
4. Данные через `server`: список, поиск, превью.
5. Клавиатура (§4).
6. Журнал буфера (§3.2) с контекстным меню.
7. Окно управления (§3.3).
8. Движение (§1.5) последним проходом — чтобы анимации не мешали отладке логики.
9. Тесты U-1…U-20.

Пункты 2, 3 и 8 не касаются DOM-контракта, поэтому не могут сломать тесты.


## W2 — approved override
Paper light and micro 11–12px default; rail + sliding groups drawer, table and preview. Single click selects/previews; double click opens editor. CRM pin metadata is the only source of the Ctrl+Shift+Q quick menu. Native quick window fixed at 340×370 logical pixels, scaled by the selected monitor DPI (clamped to available monitor work area), list scrolls. Monitor/DPI live acceptance is separate from web viewport tests. Settings profiles sync only ui/order/hotkeys, no prompts, clipboard contents, machine paths or credentials. Coffee payment destination remains unresolved and disabled rather than guessed.


### W2 navigation and input contract

Settings preserve all seven original sections (service, hotkeys, look, order, clipboard, library, diagnostics), add Cloud and About, and expose a Mini-CRM return link. All ten links follow their visible tab order; exactly one settings section is shown and aria-current names the active section. The default pinned-menu shortcut is Ctrl+Shift+Q (`^+q`). Single click selects; double click opens the editor, while Enter attempts insertion in the quick selector. Broken-prompt error state remains tested via Enter rather than the former second-click insertion behavior.
